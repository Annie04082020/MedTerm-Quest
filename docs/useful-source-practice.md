# Deterministic source practice

The original deterministic practice engine remains available beside the broader tiered authoring pipeline. It reconstructs explicit definition matching/MCQs and bounded positive-ratio exercises from source structures. Answers, explanations and derived arithmetic have separate evidence bindings.

Definitions retain literal English terminology. Formula exercises distinguish source equations and units from chosen exercise premises and computed results. Exact activity validation, transactional insertion and stable IDs prevent silent replacement of existing questions or history.

These constructions are a constrained subset, not a coverage requirement for every medical sentence. Other supported facts can enter the explicitly provisional Tier B bank under the [current policy](tiered-bank-acceptance.md). Source matching is not medical verification.

Legacy concepts/progress remain preserved. [Weekly learning](phase3-acceptance.md), [manual exchange](phase4-manual-sync.md) and [Android packaging](android-apk.md) build on the same core. Private course acceptance evidence stays in managed local data.
